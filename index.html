添加读过的论文

在功能菜单中点击「添加论文」，选择原文 PDF 和完整中文解读 HTML，检查自动生成的首页封面，填写标题、主题和笔记，点击「上传并加入书架」。首次使用先连接拥有本仓库写入权限的授权码。

回到这里，再次找到它

提交后打开右上角功能菜单，点击「刷新 GitHub 论文」。搜索覆盖标题、作者、期刊、主题和笔记，主题标签可以组合筛选。

原文和解读一起阅读

点击封面打开详情，分别进入原文 PDF、中文解读和期刊页面。解读保留原有图文与交互；导出按钮保存书架的文献信息与链接。

GitHub Pages 托管页面。站内上传会把原文、解读、封面和目录记录一并提交到仓库；旧的 GitHub Issue 记录继续兼容。授权码只在当前页面内存中使用。
