A SMALL GUIDE

你的书架，存在 GitHub。

01

添加读过的论文

点击「添加论文」，填写标题、主题与笔记，继续到 GitHub 点击 Create / Submit new issue 确认。需要登录仓库所有者 Co1dog 账号。

02

回到这里，再次找到它

提交后点击右上角刷新。搜索覆盖标题、作者、期刊、主题和笔记，主题标签可以组合筛选。

03

随时补充想法

在论文详情点击「在 GitHub 编辑」，修改 JSON 中的笔记或重点收藏标记，保留格式。关闭对应 Issue 即可从书架移除；重新打开即可恢复。

GitHub Pages 托管页面，GitHub Issues 保存记录；页面只展示仓库所有者创建的记录。正文笔记按纯文本显示。网页不上传论文 PDF，原文通过链接打开。
